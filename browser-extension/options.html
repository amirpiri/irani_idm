Irani IDM — Browser integration

Choose whether this extension may transfer your browser download URLs to the Irani IDM desktop application.

What will be transferred?

When you start an HTTP or HTTPS download, the extension sends its complete URL (including query parameters) to the Irani IDM desktop application on this computer using the local iranidm:// protocol. URLs can contain account identifiers or temporary access tokens.

What happens next?

Irani IDM saves the URL in its local download history (downloads.json) so it can restore downloads after a restart. The app requests the file from the URL's website, or through the proxy you configured. To show the server's country, the app may send that server's IP address (not the download URL) to ipwho.is.

Who receives the information?

The URL goes to Irani IDM on this device and then to the file host (and your configured proxy, if any) for the download. The extension publisher does not receive your download URLs. The extension does not use analytics or inspect page contents, cookies, passwords, or unrelated browsing history.

What happens if you decline?

Your browser downloads continue normally and are not handed to Irani IDM by this extension. You can change this setting at any time from the extension's Options page.
